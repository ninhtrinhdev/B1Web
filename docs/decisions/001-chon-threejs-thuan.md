# 001 – Dùng Three.js thuần + Vite (không dùng React Three Fiber)
**Bối cảnh:** nhóm 5 sinh viên, dự án đầu tay, mục tiêu chính là hiểu cách 3D web hoạt động.
**Quyết định:** Three.js thuần, JavaScript, Vite làm công cụ build. UI bằng HTML/CSS thường.
**Hệ quả:** viết nhiều code "nối dây" hơn, nhưng nhìn thấy rõ renderer, scene, camera, vòng lặp. Có thể chuyển sang framework ở giai đoạn sau nếu UI phức tạp.
